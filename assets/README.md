# OwnerOS asset pack · anatomy-of-light

Cinematic organ plates for the OwnerOS cockpit. One organ per screen:

| asset | screen |
|---|---|
| mind.webp (+ mind-loop.mp4) | Today |
| galaxy.webp | Brain |
| heart.webp | Projects |
| droplet.webp | Capture |
| dandelion.webp | Launch |
| strata.webp | Files |
| seedpods.webp | Roadmap |

Generated 2026-08-12 (Nano Banana Pro 2K + Seedance 2.0 loop). `manifest.json`
carries hashes. Clone into the OwnerOS app folder as `assets/`; the screens
reference `/assets/<name>` and need nothing else. Local-first: no runtime fetches.
